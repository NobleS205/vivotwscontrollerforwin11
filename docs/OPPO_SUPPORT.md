# OPPO / 一加 / realme 支持说明（v3.37）

本文件说明本程序对 OPPO 系耳机的实现范围、协议来源与已知限制。
**能力以耳机回包为准**，不按型号名猜——这与 vivo（官方 `tws_config.json`）、
华为（上游 handler 表）不同。

## 1. 连接通道

控制通道是**经典蓝牙 RFCOMM（SPP 风格）**，不是 BLE GATT（LE Audio 才切 GATT）。

| 项目 | 值 |
| --- | --- |
| 主服务 UUID | `0000079A-D102-11E1-9B23-00025B00A5A5`（SDP 名 `ELNK`） |
| 旧型号 UUID | `00001107-D102-11E1-9B23-00025B00A5A5` |
| 兜底 | 标准 SPP `00001101-0000-1000-8000-00805F9B34FB` |
| 通道 | 优先由 SDP 查；Enco X4 实测为 15，失败时显式试 15 |

前置条件：耳机必须已与 Windows 配对并处于连接状态（先播放一下声音），
程序不会主动呼叫未连接的耳机。

## 2. 帧格式

```
AA | LEN(base-128 变长) | CTRL | 00 | [FSN] | CMD(u16 LE) | SEQ | PLEN(u16 LE) | payload
```

- 无校验、无加密；
- 响应 `CMD = 请求 | 0x8000`，并回显请求的 `SEQ`；
- 响应 payload 第 1 字节为状态：`00` 成功，`0E` 需要佩戴，`0F`/`09` 忙，`10` 电量低；
- 分片帧（CTRL 低 2 位非 0）当前丢弃，本程序只用短命令。

电量查询示例（与 Enco X4 实测逐字节一致）：

```
AA 07 00 00 06 01 F0 00 00
→ AA 0F 00 00 06 81 F0 08 00 | 00 03 01 C6 02 C6 03 46
```

## 3. 已接入的命令

| 功能 | 查询 | 设置 | 说明 |
| --- | --- | --- | --- |
| 握手 | `0x0100` | — | 回能力位图 |
| 产品 ID | `0x0103` | — | 暂未用于型号识别 |
| 事件订阅 | `0x0200` / `0x0205` | — | 订阅 01/02/03（电量 / 佩戴 / 降噪） |
| 固件 | `0x0105` | — | CSV 三元组 → `116 / 116 / 100` |
| 电量 | `0x0106` | — | bit7=充电，bit0–6=百分比 |
| 佩戴 | `0x0109` | — | bit0 出盒、bit1 入耳 |
| 降噪 | `0x010C [01 01]` | `0x0404 [01 01][掩码]` | protocolIndex：1 降噪 / 0 关闭 / 2 通透；子档 4/5/6/7/11 |
| 空间音频 | `0x012A` | `0x0422 [0/1/2]` | 0 关 / 1 固定 / 2 头部追踪；老固件回退功能开关 27 |
| EQ | `0x010F` | `0x0406 [预设]` | 预设名按 OPPO「大师调音」 |
| 功能开关 | `0x010D` | `0x0403 [id][0/1]` | 6 低延迟 / 27 空间音效 V1 / 59 头部追踪 |
| 查找耳机 | — | `0x0400 [1/0]` | 50 秒或入盒自动停止 |
| 主机时间 | — | `0x8500 [00][unix u32]` | 应答耳机 `0x0500` 请求 |

## 4. 能力判定

| 能力 | 何时出现 |
| --- | --- |
| 降噪 | `0x810C` 上报的档位**不是**「仅关闭」 |
| 空间音频 | 收到 `0x812A`，或功能开关 27 / 59 有回读 |
| 游戏模式 | 功能开关 6 有回读 |
| EQ / 佩戴 / 查找 | 连接即有（命令全系通用） |
| 多设备列表 | **暂不提供**（`0x0112` / `0x0429` 未接入） |

这样 `OPPO Enco Air3` 这类无 ANC 型号不会凭空多出降噪按钮；
`Enco X4` 即使型号名被改掉，只要回包正常，功能照样出现。

## 5. 型号识别

放行三条产品线前缀：`OPPO Enco`、`OnePlus Buds`（含 `Nord Buds`）、
`realme Buds`。型号表见 `oppo/oppo_models.py`（约 60 款，仅用于规范名显示）。
未列出的新型号按家族放行，显示「OPPO / 一加 / realme 耳机（家族兼容）」。

`OPPO Find X8`、`OPPO Watch`、`OPPO Pad`、`OnePlus 13`、`realme GT7`
等非耳机设备不会被识别，也不会触发弹窗。

## 6. 已知限制

- **未真机验证**：协议来自 EncoDeck（Enco X4 实测）与 OPPO-Earbuds
  （Buds3 Pro 实测）的公开记录；本程序只在演示模式下跑通全链路。
- **空间音频写入选路**：优先 `0x0422`；若无响应或被拒，回退功能开关 27
  （仅开 / 关，没有头部跟踪）。
- **EQ 预设名**：不同型号可用预设不同（丹拿原声 / 高解析等），
  写入未知预设时耳机可能回错误码，界面以回读为准。
- **未实现**：自定义 EQ、触控手势、双设备列表管理、贴合度检测、固件升级。
- **LE Audio**：只用经典 RFCOMM；LE Audio 下需走 GATT，本程序未实现。
