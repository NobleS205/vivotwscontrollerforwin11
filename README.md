## 支持型号

程序**按蓝牙名称自动判断品牌与型号**，内置能力矩阵自动隐藏耳机不支持的控件。

### vivo / iQOO（私有协议）

覆盖官方 `tws_config.json` 声明的 **41 个型号**（vivo TWS 1~5 全系、A1~A5、
Air / Air2 / Air3 / Air3 Pro / Air Pro、Neo、X1，iQOO TWS 1~5 与 Air 全系）。
完整能力表见 [`docs/VIVO_SUPPORT.md`](docs/VIVO_SUPPORT.md)，
或运行 `python tools/vivo_audit.py` 现场打印。

- **TWS 5 / 5 Pro / 5 Hi-Fi / iQOO TWS 5（v4 协议）**：降噪、空间音频、低延迟、双连
- **TWS 4 / 4 Hi-Fi（v4 协议）**：降噪、低延迟、空间音频
- **TWS 3e、Air3 Pro（v3 协议）**：支持降噪 / 通透；无空间音频，双连为强制能力

- **TWS Air / Air2 / Air3 / A1~A5 / Neo / 5i 等入门型号**

### 华为 / HONOR（OpenFreebuds 驱动）

重点验证与适配：

| 型号 | 注册表键名 | 能力 |
| --- | --- | --- |
| **FreeBuds Pro 5** | `HUAWEI FreeBuds Pro 5` | 降噪、EQ、低延迟、佩戴、双连、固件 |
| **FreeClip 2** | `HUAWEI FreeClip 2` | EQ、低延迟、佩戴、双连、固件（**无 ANC**，降噪控件自动隐藏） |

## 快速开始（源码运行）

需要 Windows 10 / 11 与 Python 3.9+（64 位，建议 3.11 / 3.12）。

```bat
:: 1. 先在 Windows 设置里把耳机配对好（蓝牙开关打开，与手机断开）
:: 2. 安装依赖
pip install -r requirements.txt

:: 3. 正常运行（托盘常驻；会自动识别已连接的耳机）
python app.py

:: 4. 不连耳机先看界面（两个品牌各一个演示入口）
python app.py --demo            :: vivo TWS 演示
python app.py --demo=huawei     :: 华为 FreeBuds Pro 5 演示
```

也可以双击 `run.bat`（首次自动安装依赖）。

- 启动后会**先自动识别**当前已连接的耳机；没识别到才回退到「上次使用的设备」，
  首次启动则弹出面板引导手动选择。
- 浮窗弹出方式：`Ctrl + Alt + V`、左键点托盘图标、或按 `Win + A`（默认关闭跟随）。
- 托盘右键菜单：自动识别开关、连接设备（自动列出 vivo / 华为两边的已配对耳机）、
  两个品牌的演示模式、深浅色、开机自启、关闭按钮行为、是否跟随 Win+A / 系统控制中心。
- 浮窗设置菜单（⚙）：重连 / 选择设备 / **演示模式**（vivo·华为二选一）/ 自动识别 /
  深色 / 日志 / 关闭按钮行为 / 自动收回 / 退出 / **关于**（版本与作者）。
  折叠、固定仍然用标题栏右上角的 ⌄ / 📌。
- 浮窗标题栏的 ⌄ / ⌃ 可切换**折叠 / 展开**两态：折叠态只显示耳机电量与紧凑降噪切换。
- 自动识别弹出的面板若 **5 秒内没有点击**，会自动收回（浮窗设置菜单可关）。

## 打包成 EXE（一键）

```bat
:: 在项目根目录双击，或命令行执行 build.bat
```

脚本会自动完成三步：① 安装 PySide6 → ② 安装 / 更新 PyInstaller（≥6.0）
→ ③ 按 `VivoPodsCC.spec` 打包，产物为 **`dist\VivoPodsCC.exe`**
（单文件、64 位、无控制台窗口）。

- 目标机**无需安装 Python**，双击 exe 即可运行；
- 托盘菜单的「开机自启动」在 EXE 模式下写入 exe 自身路径到
  `HKCU\...\Run`（不需要管理员）；
- **v3.17 起 spec 会额外收集 `pods/`、`huawei/` 与 vendored 的 `openfreebuds`**：
  这些模块是运行时才加入 `sys.path` 的，PyInstaller 静态分析看不到，所以必须
  显式 `collect_submodules`，否则 EXE 里一选华为耳机就 `ImportError`。

> 注意：请用 **64 位 Python** 打包。`bthprops.cpl` / `ws2_32.dll` 是系统组件、
> 不需要打包，但 exe 必须是 64 位才能正常调用蓝牙接口。
