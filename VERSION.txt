VivoPods Controller
===================

显示版本（关于页显示）: V11.45.85
构建版本（本包标记）  : v3.34
构建时间             : 2026-11-05 00:27 (GMT+8)

本包内容为 v3.34，包含：
  - 自动弹窗只认支持型号（v3.34）
      · 连接 HUAWEI / HONOR 手机、笔记本、手表、音箱时不再弹面板
      · 未适配型号（例如 FreeBuds 7）既不弹窗，也不再尝试连接
      · 手动选择列表同样只列型号表内设备
  - 同一台设备在「保持连接」期间最多弹一次
      · 连接失败后的 60 秒兜底重连改为静默，不再每分钟弹窗
      · 设备断开后重新连上，会正常再弹一次
  - 睡眠 / 锁屏恢复（v3.34）
      · 唤醒或解锁后自动重挂托盘图标（Windows 会重建通知区域）
      · 断开旧链路并重连当前耳机，修掉「后台挂载消失」
      · 自动识别重新读取当前蓝牙状态，不再沿用睡眠前的快照
  - 桌面快捷方式：build.bat 打包完成后自动在桌面生成
    「VivoPods Controller」，指向根目录的 VivoPodsCC.exe
      · 图标用 EXE 内置的耳机图，不再是 Python 默认图标
      · 打包版首次运行 / 换了目录时自动补一次；手动删掉后不再反复生成
      · 桌面路径读注册表，兼容 OneDrive 重定向（不会建到看不见的目录）
      · 运行不再需要点 run.bat
  - 图标统一为耳机实物图：关于页、窗口任务栏、托盘、EXE 文件图标同一张
      · 深色背景用浅灰原图，浅色背景用压暗版（否则白底上看不见）
      · EXE 图标内嵌 16~256 九种尺寸
  - vivo / iQOO 型号能力表补齐到 41 个（官方 tws_config.json 全量）
      · 型号名与能力只维护一份（vivo_models.MODELS），不再两份表各抄一遍
  - 新增 tools/vivo_audit.py：打印全部型号能力表、明确不支持清单、
    每项功能的实现状态与真机风险；--doc 生成 docs/VIVO_SUPPORT.md
  - 降噪兜底收紧：只有耳机真回报「降噪 / 通透」才补出分区，只回「关闭」不算
  - 降噪分区以耳机回报为准（v3.29）：名字带后缀 / 被改名也能正常显示
  - 面板刷新容错：换实物图、重建 EQ 失败不再连带藏掉整块功能区
  - TWS 3e 双连修正：该型号双连硬件常开，不再显示空的多设备分区、也不再空查
  - 后台常驻：面板收起、挂机数小时也不会自己退出
      · 槽函数 / 后台线程 / 析构里的异常只写日志，不再结束进程
      · 原生崩溃写 crash.log（faulthandler），可查可定位
  - 崩溃自愈：独立看门狗盯着主进程，检测到崩溃痕迹就自动拉起一次
      · 被任务管理器 / 安全软件强杀时不重启（手动杀死就是真死）
      · 1 小时内最多拉起 3 次，避免「一启动就崩」的死循环
  - 托盘自愈：Explorer 重启把图标弄丢时，20 秒内自动重新挂载
  - 单实例：重复双击只唤出已有面板，不再起第二个托盘 / 看门狗
  - 日志（%LOCALAPPDATA%\VivoPodsCC\）：runtime.log（启动 / 退出 / 每 10 分钟
    心跳 + 内存占用 + 连接时的型号与能力）、crash.log、watchdog.log
  - vivo 耳机在仓充电图标：放回仓、开盖连接时左右耳也显示充电闪电
  - 新增 tools/battery_probe.py：抓取 vivo 电量 / 佩戴原始报文用于排查
  - 断连 1~3 秒内更新；切换设备立即清空旧读数
  - 连接后主动查询佩戴状态（不必摘戴一次）
  - FreeClip 2 佩戴支持左右耳区分（左耳未佩戴 / 右耳未佩戴）
  - FreeClip 2 连接时耳机图标切换为其实物图
  - 关于页只显示居中的「关于」，返回后佩戴 / 连接状态回到原位
  - 二级菜单：演示模式合并为子菜单；移除「折叠面板」「固定浮窗」
  - 折叠动画到点强制落位（不再卡在半空）
  - 点面板以外自动收回；自动弹出 5 秒无操作收回
  - 华为 FreeBuds Pro 5 / FreeClip 2 + vivo / iQOO 双品牌支持

运行：打包版双击桌面「VivoPods Controller」或根目录 VivoPodsCC.exe；
      源码运行双击 run.bat（需 Python 3.10+ 与 PySide6）
打包：双击 build.bat（需 PyInstaller 6+），完成后自动建桌面快捷方式
